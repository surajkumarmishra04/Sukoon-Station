## 📖 About

**Sukoon Station** is a minimal cinematic music website created to provide a calm and immersive listening experience.

The website combines:

- 🎵 Music
- 🖼️ Cinematic background images
- 🕐 Live 12-hour clock
- 🎧 Custom music player
- 📋 OG Playlist system
- 😴 Sleep Timer
- 🪟 Glassmorphism interface

The main goal is to keep the interface simple while making the music experience visually beautiful.

---

## ✨ Features

### 🎵 Music Player

- Play / Pause
- Previous track
- Next track
- Music progress bar
- Current time
- Total duration
- Track artwork
- Song title
- Artist information

### 📋 OG Playlist

The website uses an **OG Playlist** system.

Playlist sections are generated dynamically using JavaScript.

You can add new playlists without modifying the HTML.

For example:

- 🌅 Morning Music
- 🎶 Old Songs
- 🏋️ Gym
- 🌙 Night
- 📚 Study
- 🚗 Safar
- 💪 Workout

Future playlists can be added directly from the playlist configuration inside `script.js`.

---
